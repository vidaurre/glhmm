.. glossary::
   :sorted:

   covtype
      The covariance type. Controls the mathematical shape of each state. ``'full'`` gives each state its own covariance matrix, capturing co-activation between brain regions. ``'diag'`` fits only per-channel variances. Use ``'full'`` for most neuroimaging work.

   δ (dirichlet_diag)
      The Dirichlet diagonal. Controls how persistent states are: high δ produces long, stable states; low δ allows rapid switching. Set via the ``dirichlet_diag`` parameter when creating the model (default: 10).

   fractional occupancy
      The proportion of time the model assigns to each state. A common summary measure derived from γ, averaged across a recording or across subjects.

   free energy
      A measure of how well a trained model fits the data. Higher is better. A model with more states will always have a higher free energy, so free energy alone cannot be used to choose K. See the state number selection notebook for how to compare models properly.

   γ (Gamma)
      The state time course. The main output of training: a matrix of shape ``(n_timepoints, K)`` where each row gives the probability of being in each state at that moment. Rows sum to 1. Called ``Gamma`` in the code.

   GLHMM
      Gaussian-Linear Hidden Markov Model. A model variant that jointly learns brain states and their relationship to a second variable, such as behaviour, reaction times, or task conditions.

   HMM
      Hidden Markov Model. A model that finds recurring patterns of activity in time series data by assuming the data is generated by a sequence of hidden states that switch over time.

   K
      The number of states the model is asked to find. Chosen by the user before training. There is no single correct value; a practical approach is to train models with several values of K and compare results.

   MAR-HMM
      Multivariate autoregressive HMM. States are defined by autoregressive coefficients, making them sensitive to specific oscillatory frequencies and amplitudes. Requires preprocessing with ``build_data_autoregressive()``.

   model_mean
      Controls whether each state has its own mean activation level (``'state'``) or only its own covariance structure (``'no'``). Use ``'no'`` for demeaned or standardised data.

   n_parcels
      The number of brain parcels, regions, or channels in the data.

   n_samples
      The total number of timepoints across all sessions.

   n_sessions
      The total number of recording sessions.

   n_states
      The number of hidden states in the model. Set by the parameter K.

   state lifetime
      The average duration a state persists before the model switches to another state. Derived from γ using ``utils.get_life_times(Gamma, indices)``.

   state mixing
      Whether the model captures within-session state transitions, rather than assigning most of a session to a single state. For more information, see Ahrends et al. (2022) `here <https://pubmed.ncbi.nlm.nih.gov/35217207/>`_.

   TDE-HMM
      Time-delay embedded HMM. States are defined by the covariance of lag-embedded data, capturing spectral content such as alpha, beta, or gamma oscillations. Well suited to whole-brain MEG or EEG recordings. Requires preprocessing with ``build_data_tde()``.
